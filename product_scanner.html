How to add products:
  1. Fill in all required fields (name, price, ID)
  2. Product ID can be manually entered or auto-generated
  3. Select a category to organize your products
  4. Add an optional description for more details
  5. Click "Add Product" to save to the system
Tip: Use simple, unique IDs for easy scanning. For example: "COF001" for coffee, "TEA001" for tea.
Cafe Tip: Add cafe-specific categories like Coffee, Tea, Pastries for better organization.
